## 3. My Reflection on AI Use

During Lab 3, I used ChatGPT mainly as a development assistant rather than relying on it to complete the project without verification. It was useful for understanding the assignment requirements, planning authentication and authorization logic, generating test ideas, and helping with repetitive implementation such as API and UI scaffolding. I still had to verify the generated code against the Lab 3 specification and test it locally because some suggestions did not exactly match my existing code structure or could affect previous Lab 2 functionality. One important example was the transition from the old Requester-based flow to authenticated users: I had to check that ticket ownership was enforced from the authenticated session and that existing Requester features were not broken. I also caught cases where the generated implementation or test assumptions did not match the actual UI behavior, so I adjusted the code and tests before considering the work complete. Overall, AI helped me work faster and understand unfamiliar parts of the system, but I was responsible for reviewing, testing, and making the final implementation decisions.
