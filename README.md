# TokTickIT

TokTickIT is a full-stack IT Service Desk application developed for CPE334 Lab 1.

## Technology Stack

- Frontend: React + TypeScript + Vite + Bootstrap
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Testing: Vitest + Supertest
